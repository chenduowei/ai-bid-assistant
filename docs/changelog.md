## [0.24.0] — 2026-11-06
- **浮钮根因修复**：回顶部只在最下方可点、回到底部压根看不见，根因是 `.page` 的入场动画 `page-in` 以 `both` 填充保留了 `translateY(0)`，使 `.page` 成了 `fixed` 定位的包含块，两个浮钮被钉在页面内容底部——回顶部只有滑到底才看得见，回到底部则永远看不见（滑到底时按规则隐藏、半路时在视口之外）。修法：动画收尾改 `transform: none`，视觉不变，浮钮回到视口定位；`view-in` 同改，防同类问题。另出现阈值 400→200px，下滑一点就出现，随时可点。
- **品牌角标改正方形**：固定 64px（桌面）/ 52px（窄屏），与右侧文字块高度基本一致；v0.23.0 的 `stretch` + `aspect-ratio` 在按钮元素上没按预期走，拉成了长方形。
- **版本号移到页眉**：从页脚移到同步状态与邮箱同一行（右对齐），一进主界面就能看到。
- **README**：保持简单高级，标题与小节加了少量表情符号点缀。
- 测试 63 个全过；无需 Supabase 迁移。

## [0.18.2] — 2026-11-05
- **AI 分析提速**：分块从 24k 字符放大到 48k（14.5 万字文档 7 块减到 4 块，少 3 次往返）；分块摘要改 2 路并行（worker 池，摘要拼回时仍按原序），限流 429 时先退避重试一次，再失败的块逐块串行再试一次，还失败才整体报错；取消与 401 不重试。
- **进度是真的在走了**：模型请求改流式（stream:true），边收 token 边在本次请求的进度带里推进（摘要 10→80、最终调用 85→95），文案带已用时间与按已完成块平均耗时估的剩余时间；中转不支持流式（不回 SSE）时自动回退一次非流式，不影响出结果。流式本身不减少总耗时，但等待不再是干等。
- 测试 58→64（新增默认分块、SSE 解析 3 组，流式并行 + 429 重试 + 非流式回退 2 组端到端打桩测试）；无需 Supabase 迁移。
