## 运维备忘

1. 首次部署：复制 `supabase-config.example.js` → `supabase-config.js` 并填入真实 URL / anon key。
2. 在 Supabase SQL Editor 执行 `supabase.sql`（含增量迁移段）。
3. 若曾把真实 key 提交到公开仓库，请在 Supabase 控制台轮换 anon key。
4. AI 功能需用户在界面「AI 设置」中自行填写兼容接口的 API Key。
5. **提交 Git 前务必确认 `supabase-config.js` 未被追踪**（应在 `.gitignore` 中）。
